# নেটওয়ার্কিং শেখা — বাংলায় সম্পূর্ণ গাইড

শূন্য থেকে শুরু করে **CCNA** পর্যন্ত — বাংলায় নেটওয়ার্কিং শেখার একটি উন্মুক্ত, সম্পূর্ণ বিনামূল্যের কোর্স। সহজ উপমা, হাতে-আঁকা ডায়াগ্রাম আর হাতে-কলমে কমান্ড দিয়ে সাজানো।

🌐 **লাইভ সাইট:** [networking.najmulislam.dev](https://networking.najmulislam.dev)

---

## 📚 কোর্সের কাঠামো

চারটি স্তরে সাজানো, প্রতিটা আগেরটার উপর দাঁড়িয়ে:

| মডিউল | পেজ | কার জন্য | যা শিখবেন |
|---|---|---|---|
| **০০ — শূন্য থেকে** | `zero.html` | একদম নতুন, কোনো পূর্বজ্ঞান ছাড়া | নেটওয়ার্ক কী, IP অ্যাড্রেস, OSI মডেল, প্যাকেট, DNS · DHCP · NAT, বেসিক কমান্ড |
| **০১ — ভিত্তি** | `beginner.html` | বেসিক জানা, গভীরে যেতে চান | বাইনারি, সাবনেট · CIDR, Ethernet ফ্রেম, TCP/IP মডেল, DHCP-র DORA প্রক্রিয়া |
| **০২ — প্রোটোকল** | `intermediate.html` | সফটওয়্যার ইঞ্জিনিয়ার ও আর্কিটেক্ট | TCP গভীরে, UDP, routing table, ARP, DNS · TLS, HTTP/1.1 · 2 |
| **০৩ — CCNA** | `deep-dive.html` | পরীক্ষা প্রস্তুতি | VLAN · Trunk, STP, OSPF, ACL, NAT · DHCP, Cisco config ও স্টাডি প্ল্যান |

`index.html` হলো ল্যান্ডিং পেজ — এখান থেকে সব মডিউলে যাওয়া যায়।

## 🛠 টেক স্ট্যাক

- বিশুদ্ধ **HTML + CSS + সামান্য vanilla JavaScript** — কোনো ফ্রেমওয়ার্ক, বিল্ড স্টেপ বা ডিপেন্ডেন্সি নেই।
- প্রতিটা পেজ একটা **স্বয়ংসম্পূর্ণ HTML ফাইল** (CSS ও JS ভেতরেই ইনলাইন করা)।
- ডায়াগ্রামগুলো হাতে-লেখা **inline SVG** (কিছু ক্ষেত্রে অ্যানিমেশনসহ)।
- ফন্ট: [Hind Siliguri](https://fonts.google.com/specimen/Hind+Siliguri) (বাংলা) ও [JetBrains Mono](https://fonts.google.com/specimen/JetBrains+Mono) (কোড)।
- হোস্টিং: **GitHub Pages** (কাস্টম ডোমেইন `CNAME`-এ)।

## 🚀 লোকালি চালানো

কোনো বিল্ড লাগে না — যেকোনো একটা করলেই হবে:

```bash
# সরাসরি ব্রাউজারে index.html খুলুন, অথবা একটা স্ট্যাটিক সার্ভার চালান:
python -m http.server
# তারপর http://localhost:8000 খুলুন
```
